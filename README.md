# Nike Sales Performance Dashboard | Power BI

## Project Overview

An interactive Power BI dashboard developed to analyze Nike's sales
performance, key business KPIs and growth trends over time.

## Objectives

- Analyze overall sales performance
- Track key business KPIs
- Identify growth trends
- Compare performance across different dimensions
- Generate actionable business insights

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modelling
- Data Visualization

## Key KPIs

- Total Profit
- Cost of Good's Sold
- Units Sold
